## Why this exists

Handoff quality is usually where small ambiguity turns into rework. This checklist is focused on reducing implementation gaps.

## Checklist

1. Define key user flows and states.
2. Document empty, loading, and error states.
3. Specify constraints, validation, and permissions.
4. Attach source components and token references.
5. Confirm acceptance criteria with engineering.
